# Activity 1 – Setup Note

I installed the Microsoft C/C++ extension in VS Code (version 1.144.0), then installed the GCC compiler through MSYS2 using `pacman`. The first `pacman -Syu` failed with "Operation too slow" errors from the mirror because my connection was slow, so I ran the update again until the packages downloaded properly. After adding `C:\msys64\ucrt64\bin` to the PATH, `gcc --version` still showed an old MinGW GCC 6.3.0, so I used `where gcc` and found that `C:\MinGW\bin` was listed before the MSYS2 folder. I removed that old entry from the PATH, opened a new Command Prompt (PATH changes only apply to new terminals), and both `gcc` and `g++` then reported version 16.2.0 from MSYS2. Finally I wrote `hello.c`, compiled it with `gcc hello.c -o hello.exe`, ran `.\hello.exe`, and it printed "Hello, World!".
